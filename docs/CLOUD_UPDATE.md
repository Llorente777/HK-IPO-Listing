# 云端更新接入检查点

目标仓库：`Llorente777/HK-IPO-Listing`。现有公开网站第30版保持不变。

## 当前阶段

本工作流是云端采集与完整验收，不代表网站已经具备公众更新功能。
仅支持仓库授权人员手动发起；在端到端写入验证完成前不新增自动计划、
不提交部分数据、不覆盖Sites、不展示可用的公众更新按钮。

1. 恢复已保存的官方快照及历史证据，保留真实日期和哈希；不将恢复称为重新下载。
2. 安装PDF读取依赖，使用已提交的依赖锁文件。
3. 重新采集HKEX/HKEXnews、SSE/SZSE；若失败，标准化数据恢复上一成功版。
4. 数据规则、Python测试、类型检查、前端测试、生产构建全部通过后，生成内容哈希命名的候选发布包。
5. 发布包和原始证据保留在本次GitHub Actions产物；失败运行不生成可发布候选。

此前的每周工作流缺少提交的pnpm锁文件、PDF依赖安装和历史证据恢复，
且只提交部分生成文件。这次先修复可迁移性，再验证公众请求与网站切换。

## 下一阶段的安全边界

访客只能请求执行固定的官方采集器，不能上传任意数据、修改采集URL或运行代码。
需要服务端持久队列、去重/限频、运行状态和失败提示；云端结果写入必须验证受信任的仓库及工作流身份。
网站页面、检索、统计、筛选CSV和全量下载必须固定在同一个不可变数据版本，全部上传并校验后才切换。
私密凭据不得进入源码、浏览器、公开仓库或聊天。旧版网站和成功快照保留用于回滚。

## 研究内容不伪自动化

官方结构化源采集与媒体/公司公告的人工研究是不同流程。
密交新闻分档、终止检索结论和复核日只在实际核查后更新，
定时运行不能把旧证据日期统一刷新，也不能假称穷尽媒体或公众号。
