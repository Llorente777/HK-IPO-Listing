# 官方来源映射

| 业务字段 | 首选证据 | 备选官方证据 |
|---|---|---|
| 最终发售价、配发、最终募资 | 最终配发结果公告 | 正式招股书 |
| 发行股数、招股区间 | 正式招股书 | PHIP |
| 监管审核处理中申请宗数 | 港交所《首次公开招股申请、除牌及停牌报告》 | 无 |
| 当前公开AP/PHIP记录、同一ID递交轮次 | HKEXnews 申请版本/PHIP索引 | 无 |
| 新上市状态 | 港交所新上市资料与新上市证券 | 上市公告 |
| A→H 身份 | 招股文件内 A 股代码 | 上交所、深交所、北交所或上市公司公告 |
| 境外上市备案 | 中国证监会备案公开信息 | 发行人正式公告 |
| A 股价格 | 对应境内证券交易所 | 无 |
| H 股价格 | 香港交易所 | 无 |
| HKD/CNY 汇率 | 中国人民银行、外汇管理局或香港金管局 | 无 |

优先级：最终配发结果/最终发售价/稳定价格行动结束公告 ＞ 正式招股书 ＞ PHIP ＞ Application Proof ＞ 港交所新上市资料 ＞ 港交所月度/年度统计 ＞ 境内监管机构公告。新闻、研报及商业终端不作为最终证据。
